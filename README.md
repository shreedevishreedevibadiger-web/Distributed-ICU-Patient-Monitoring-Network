# Distributed-ICU-Patient-Monitoring-Network
In a typical ICU, each patient is connected to medical devices such as bedside monitors, ventilators, infusion pumps, and pulse oximeters. These devices produce important readings, but the data may be spread across separate screens, systems, or hospital locations. This project brings those readings together so clinicians can review patient status across several beds, wards, or participating hospitals.

The system is designed to detect changes in a patient’s condition and alert clinical staff when readings cross configured thresholds or when a concerning pattern appears. It can also retain patient observations for review over time, supporting handovers, audits, and clinical analysis. The network is intended to help clinicians make timely decisions; it does not replace their judgment or independently diagnose or treat patients.

Application:
   Monitors ICU patients’ vital signs in real time.
   Sends alerts when readings become abnormal.
   Lets doctors view patients remotely.
   Tracks patient readings over time.

Conclusion: The Distributed ICU Patient Monitoring Network helps medical staff monitor patients in real time, receive alerts, and respond more quickly to changes in a patient’s condition.
